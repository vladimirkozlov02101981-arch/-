## По картам (главное)

**Долина.** Кладка моста — «пластилиновые подушки» без микрорельефа, чёрные швы 10–12 px, одинаковая жёлто-зелёная кайма мха на каждом камне → кладка из эталонов (`tex_from_ref`: valley_house 800–1536×645–1000, valley_tower 0–410×760–990), шов 4–6 px L≈35–45, мох пятнами на 10–20 % камней, детали гранита ±12 L. Арки — клинчатые камни 28–36 px и тень свода 10–14 px. Овальные дыры в пазухах арок — убрать/окулюс. Плющ векторный и равномерный (шаг ≈45 px) → вырезки, шаг 30–200 px, насыщенность 35–45 %. Трава — «гребёнка», цветы плоские. Земляной откос справа ~7/10, но темнее/мягче: gain ≈[1.17,1.17,1.13], контраст +25 %.

**Каньон.** Кремовая корка поверх породы — мыло, подтёки лесенкой 8–10 px → корка из canyon.png (0–1586×250–290), 10–16 px. Векторный декор (кактусы, водонапорная башня, камешки-шары) → вырезки из эталона. Порода на 2.5× пересушена (ВЧ 122 %): детали −20…25 %, насыщенность −10 %. Лестница без опоры, плоское дно останца — тень/кромка. Мост из одной доски-«трубы» → 2–3 доски с волокнами, верёвочные перила. Прямые срезы утёсов — шум кромки ±6–10 px.

**Арктика (минимум).** Лёд — пиксельные декали (кольца, ромбы, квадратики) → градиент #cfe6f5→#6fa3c8→#3d6f99, fbm 30–60 px ±6–8 L, 2–4 тонкие сглаженные трещины, блики. Кирпичный дом — глянцевый красный пластик → матовый ≈#6e3b2e, шов светлый 3 px, иней, без блика. Ель из «блинов» → спрайт из эталона. Скала темнее/мягче: gain ≈[1.35,1.30,1.15]; снег только на верхних гранях; точки убрать. Лесенка контуров льда и снега (10–14 px) — сглаживание hires; сосульки 2–6×8–30 px. Снежная шапка однообразна (25 px, повтор 45 px).

**Вулкан (лучше всех).** Деревянная площадка — картон → доски с волокнами, обугленные кромки. Края шахты как шов плитки → внутренняя тень 14–20 px. Обсидиановые шипы — векторные треугольники. На 2.5× порода мылится (47 %): детали базальта +50 %, лава векторными ломаными; диагональная сетка ~8 px на max — проверить карту деталей. Пятна лавы наклеены — площадь −40 %, свечение вдоль трещин.

**Замки.** Кладка — те же «подушки» → из моста castles.png (210–860×570–820), шов 3–5 px. Вертикальные заплатки с двоящимися кирпичами (x≈868–892, 1262–1288) — фаза texRef. Балки — глянцевые оранжевые полосы → −35 % насыщенности, волокна. Оранжевое свечение под ступеньками — артефакт; балка прерывается вставкой. Плющ векторный. Верх стены — «линейка».

**Город.** Эстакада — заглушка (плита с пунктиром, опоры-градиенты, висящая линия перил, кондиционеры-значки). Полупрозрачные «призраки» и светлые прямоугольники фона в вырезах. Окна пересвечены (×0.8, свечение −40 %). Балконы — сиреневый пластик. Лестницы кислотно-жёлтые. Рамы окон на max — лесенка.

**Пиратская.** Вода мультяшная (градиент, кремовая обводка, нет ряби/бликов/отражения/дна; «кольца-иллюминаторы» под водой — неверное отражение). Пояс водорослей — плоский оливковый с пилой → низ корпуса из эталона. Обшивка читается как камень → доски 24±2 px рядами, стыки через 150–300 px, волокна 1:8, болты. Окна и фонари — плоские значки. Железные полосы — заклёпки, ржавчина.

**Alien.** Порода с фильтром «тиснение/масло» (перешарп) → `tex_from_ref` из alien.png (120–1540×600–950) лоскутами 96–128 px без нерезкой маски, gain ≈[1.10,1.15,1.05], детали −30 %. Кристаллы — лиловые кляксы → гранёные осколки 6–14 px. Покров: гребёнка тёмно-бирюзовых вертикалей + оливковая полоса со ступенями → мох из эталона (100–1530×560–600), градиент 12 px. Розовые шары — «ёлочные игрушки» → кусты цветов из эталона. Гриб плоский. Мостики — неоновый пластик → трубы как в эталоне.

## 6 правок по выгоде

1. Арктика: лёд, кирпич, ель, скала (3.9 → ~5.5).
2. Пиратская: вода, пояс корпуса, доски рядами (+1.5).
3. Кладка долины и замков из эталонов, шов светлее и тоньше, лишайник пятнами, клинчатые камни, без овальных дыр и двоящихся полос (+1.5 обеим).
4. Alien: порода без тиснения, кристаллы гранями, мох из эталона, цветы вместо шаров (+1.2).
5. Векторный декор → вырезки из эталонов на всех картах (+0.5…1).
6. Чёткость 2.5× (ВЧ ≥50 % эталона; каньон −20 %) и сглаживание контуров льда, снега, корок, травы, подтёков; сборка слоёв города и свечение под ступеньками замков.
