# Главный план работ (читать сразу после CLAUDE.md и NEXT_STEPS.md)

Этот файл защищает цели от сжатия контекста чата. Порядок: сначала все просьбы пользователя из раздела A (по порядку),
затем графика и остальное из раздела B. После каждого законченного шага: тесты → версия в index.html → сборка
`node dev/build-single.cjs` → копия `dist/Territory-War.html` в корень как `Territory-War.html` (версионные копии больше
НЕ делать — пользователь попросил не копить старые) → README «Что изменено» → dev/NEXT_STEPS.md → коммит → push.
Пользователь запускает: **«Играть онлайн.cmd»** (игра с другом: окно игры + ссылка для друга в буфере) или **«Играть.cmd»**
(одному/вдвоём на ПК). Оба открывают игру в отдельном окне Chrome (иначе Edge): только там Esc не отпускает мышь.
Друг: открывает присланную ссылку в браузере или свой файл `Territory-War.html` → «По сети» → вставить ссылку.

## A. Просьбы пользователя (02.10, пакет 3) — делать все

- [x] A1. Личные настройки каждого игрока, сохраняются автоматически и восстанавливаются при следующих запусках (не сбрасываться).
      При первом запуске — нынешние настройки пользователя как значения по умолчанию.
- [x] A2. Сетевой бой: постоянные личные настройки отдельно, временные настройки боя отдельно. Хост выбирает оружие/патроны —
      действует только в его бою. После боя у гостя восстанавливаются его настройки; настройки хоста из лобби тоже не сохраняются
      сами. Постоянные настройки никогда не перезаписываются временными (сетевой бой и любой другой).
- [x] A3. Сохранённые конфигурации: несколько, со своими именами; сохранить текущие в выбранную; переключать; редактировать
      (переименовать, перезаписать, удалить); использовать для боя. Доступно в настройке сетевого боя и во всех режимах.
      Кнопка «Создать конфигурацию из текущих настроек».
- [x] A4. Галочка «Использовать по умолчанию» у любого набора (даже несохранённого): становится основным, грузится при запуске и
      при создании новых боёв. Предыдущий основной запоминается; снятие галочки возвращает прежний — пока игрок не вышел в главное
      меню (выбор: по сети / против компьютера / на одном экране).
- [x] A5. Конфигурации и «по умолчанию» хранят ВСЁ: параметры боя, всё оружие и патроны, команды, ГОРЯЧИЕ КЛАВИШИ (нужна
      перенастройка клавиш), звук.
- [x] A6. Карточка карты при наведении не делится пополам (убрать нижнюю схему-накладку).
- [x] A7. Подраздел «Непрерывный бой» у двух режимов: «Играть с другом (онлайн)» и «Против компьютера» (не на одном экране):
      оба игрока ходят одновременно; после хода следующий ход снова мой — следующим по номеру бойцом; у друга так же.
- [x] A8. Настройка «Ход: ограничен дистанцией / на любую дистанцию» — во всех режимах.
- [x] A9. Бойцы пронумерованы 1…N во всех режимах (порядок ходов понятен), имена убрать.
- [x] A10. Быстрый пропуск хода клавишей «ё» (Backquote, слева от 1) — тоже настраиваемая клавиша.
- [x] A11. Все горячие клавиши — по физической клавише (event.code), независимо от раскладки (укр/рус/англ…).
- [x] A12. Убрать клавишу Windows из списка горячих клавиш (мышь освобождает Backspace).
- [ ] A13. По завершении: обновить файлы проекта, написать дословно, какой файл запускать, и продолжать по списку.
