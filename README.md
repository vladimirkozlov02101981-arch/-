# Territory War: Frontlines

Пошаговая артиллерийская игра для браузера на основе начатого проекта. Два игрока онлайн, вдвоём на одном компьютере или бой с компьютером. Интерфейс на русском.

## Запуск

На Windows откройте **Играть.cmd**. Откроется `http://localhost:3000`.
Нужен Node.js 20 или новее. При первом запуске без папки `node_modules` скрипт устанавливает серверную зависимость из зафиксированного `package-lock.json`.

Вручную из папки проекта:

```sh
npm ci
npm start
```

Сервер раздаёт игру и обслуживает комнаты через WebSocket. Открывать `index.html` двойным щелчком не нужно. Закрытие вкладки не останавливает сервер, запущенный через `Играть.cmd`; его PID сохраняется в `dev/server.pid`.

## Один файл без установки

`node dev/build-single.cjs` (при запущенном сервере) собирает `dist/Territory-War.html` — всю игру в одном файле со встроенными картинками, звуками и шрифтами. Он открывается двойным щелчком без Node.js; доступны «Против компьютера» и «На одном экране». Для игры по сети нужен сервер.

## С другом онлайн

На этом компьютере откройте **Играть онлайн.cmd**: скрипт запустит сервер, создаст временный HTTPS-туннель через [localhost.run](https://localhost.run/docs/) и откроет игру на публичном адресе. Аккаунт не нужен; используется установленный в Windows OpenSSH. Файл `dev/tunnel-session.json` хранит текущий адрес. Для повторного запуска нужна доступность `localhost.run` из вашей сети.

1. Оба открывают **один и тот же адрес игры**.
2. Первый: «Играть с другом» → «Создать комнату» → копирует приглашение.
3. Друг открывает приглашение или вводит код из пяти символов.
4. Хост выбирает карту, состав, время хода и нажимает «В бой!».

В локальной сети второй игрок открывает `http://IP-компьютера-хоста:3000`. Брандмауэр должен разрешать Node.js во внутренней сети. Адрес `localhost` работает только на компьютере, где запущен сервер.

Для интернета нужен публичный адрес сервера с HTTPS и поддержкой WebSocket. При наличии `dev/cloudflared.exe` временный адрес без настройки роутера можно получить командой:

```powershell
.\dev\cloudflared.exe tunnel --url http://127.0.0.1:3000 --no-autoupdate
```

Откройте показанный адрес `https://….trycloudflare.com` и создавайте комнату уже на нём. Временный адрес действует, пока работают туннель, сервер и компьютер. При следующем запуске туннеля адрес меняется. Постоянный адрес требует развёртывания Node-сервера на хостинге; подготовлен `Dockerfile`, порт задаётся переменной `PORT` (по умолчанию 3000).

Адрес `lhr.life` также временный и может смениться через несколько часов. Не выключайте компьютер во время игры. Если ссылка перестала открываться, снова запустите «Играть онлайн.cmd» и отправьте другу новое приглашение.

Симуляция выполняется у хоста, второй игрок получает снимки состояния и события разрушений. Обоим нужен стабильный интернет. Перезагрузка страницы или выход хоста завершает текущий матч; восстановление после полного разрыва связи не реализовано. Это игра для дружеских матчей, без рейтинга и серверного античита.

## Управление

| Действие | Клавиши |
|---|---|
| Ходить | A / D или ← / →. Запас хода — расстояние по горизонтали от точки начала хода: назад и по лестницам можно сколько угодно, границы показаны пунктиром |
| Прыгать | Пробел; направление — A / D |
| Лестница рядом с бойцом | W / S или ↑ / ↓ |
| Прицел | Мышь; W / S для изменения угла, Shift для точного прицеливания |
| Огонь | ЛКМ или Enter; у ракет и гранат удержание задаёт силу |
| Арсенал | Tab или короткое нажатие ПКМ |
| Следующее / предыдущее оружие | E / Q |
| Категория оружия | 1–6 |
| Бинокль: вид плавно едет за мышью | Удерживать ПКМ или B |
| Камера к бойцу | C |
| Масштаб | Колесо (в небольших пределах) |
| Пропустить ход / повернуть балку или задать подкрутку гранаты | P / R |
| Чат в сетевой игре | T, затем Enter |
| Пропустить ход (сделал всё, что хотел) | Ё (слева от 1) или P |
| Убрать оружие из рук / вернуть убранное | Esc / ещё раз Esc |
| Меню (пауза, мышь свободна) / звук | Backspace или ☰ / M |
| Вернуть мышь в игру | Клик по полю боя |
| Прыжок робо-бомбы | Пробел, пока она бежит |

В сетевой игре открытое меню не останавливает общий таймер.

## Проверки и структура

```sh
npm test
npm run test:browser
npm run test:audio
node tests/tactics.cjs
node tests/online.cjs
node tests/hires.cjs
node tests/surface.cjs
python tests/test_texture_quilting.py
# После автономной сборки
node tests/single.cjs
node dev/navcheck.cjs --img
```

Браузерный тест требует установленного Chrome и работающего сервера на порту 3000. `TEST_URL` позволяет проверить другой сервер, `TEST_BROWSER=msedge` — Edge. Проверки: комнаты и изоляция, две вкладки с разными сессиями, чат, стрельба, синхронизация рельефа, свёрнутая вкладка, реванш, баллистика, укрытия, все обработчики оружия, одинаковая геометрия всех карт и безопасные точки появления, отсутствие ловушек на картах. `dev/navcheck.cjs` печатает отчёт проходимости и с `--img` сохраняет карты с отмеченными точками. Скриншоты и отчёты записываются в `test-results`.

`js/maps.js` — фигуры и растеризация; `js/levels.js` — восемь карт; `js/navcheck.js` — анализатор проходимости. `js/game.js`, `soldier.js`, `entities.js`, `arsenal.js` — симуляция. `js/audio.js` — звук. `server.js`, `js/net.js`, `js/remote.js` — сеть. `assets/maps` — локальные панорамы и миниатюры. Шрифты Russo One и Rubik (SIL Open Font License) лежат в `assets/fonts`, игра работает без интернета.

Панорамы созданы инструментом imagegen для этого проекта. Описание генерации сохранено в `assets/ARTWORK.md`. Исходные ресурсы Territory War 3 с сайта не скачивались.
